# Repository instructions

This is a public Markdown knowledge base about men's clothing and hair. It contains original notes, source records and blank practice templates, not a personal profile or a styling service.

- Keep the root README concise. Default reader-facing files without a locale suffix to English; use `.zh-CN.md` for Chinese notes. Keep the English and Chinese README navigation aligned and reciprocally linked.
- Preserve source IDs. Separate publisher descriptions, research findings, aesthetic conventions and untested proposals. Checking a catalog is not reading a book.
- Record the source URL, access date, edition and reading depth where relevant. Do not silently promote an unverified citation to evidence.
- Describe actual hair properties, garment dimensions, preferences and context. Do not derive an individual's suitability from nationality or ancestry.
- Keep personal photos, measurements, receipts, private experiment results, raw data and generated artifacts outside this repository. Blank templates belong here.
- Do not upload book scans, video downloads or unlicensed reference images. Link to authorized sources and write original summaries.
- Before committing, run `git diff --check`, verify relative Markdown links and fragment targets, compare the two README entry points, and review the staged diff for private information and unsupported claims. This documentation-only project has no application build, deployment or test suite.
