# 研究笔记模板

[模板目录](../experiments/README.zh-CN.md) · [English index](../experiments/README.md)

复制到私人目录后填写；需要公开时另写去掉个人信息的总结。空白字段表示尚未记录，不代表已经验证。

| 字段 | 填写内容 |
| --- | --- |
| 记录编号与日期 | 自定稳定编号 |
| 问题 | 本次只回答什么 |
| 当前猜想 | 预计会发生什么，为什么 |
| 来源编号与链接 | B、C、R 或待核实 P 编号 |
| 版本与定位 | ISBN、章节、页码，或视频时间戳 |
| 阅读进度 | 介绍、摘要、部分正文或全文 |
| 来源原本的说法 | 用自己的话概括，保留范围 |
| 自己的解释 | 明确与原文分开 |
| 判断类型 | 研究发现、专业技术、审美经验、待试方案或个人观察 |
| 反例与限制 | 哪些结果会让自己改变看法 |
| 比较方法 | 改什么、保持什么、观察几次 |
| 实际记录 | 尚未完成就留空 |
| 当前结论 | 支持到哪里，还有什么不知道 |
| 修订历史 | 原判断、改动与新材料 |
