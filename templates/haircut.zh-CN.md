# 剪发复盘模板

[模板目录](../experiments/README.zh-CN.md) · [English index](../experiments/README.md)

复制到私人目录后填写。参考图优先保留来源链接，个人照片使用私人记录编号，不在公开仓库填写路径或可访问链接。

| 字段 | 填写内容 |
| --- | --- |
| 记录编号与日期 | 自定稳定编号 |
| 目标与参考 | 希望保留的轮廓及来源链接 |
| 实际发质与生长方向 | 理发师现场观察与自己观察分开 |
| 改变的主要变量 | 刘海、顶部、两侧或后部 |
| 实际剪裁 | 能确认的长度与过渡，不能确认就写未知 |
| 烫发与产品 | 如有则记录，包含造型方法 |
| 日常维护预算 | 愿意花的时间与实际耗时 |
| 当天店内效果 | 感受、私人照片编号 |
| 自己第一次洗后 | 能否重现、哪里不同 |
| 后续观察日期 | 自定间隔，记录长长后的变化 |
| 比较条件 | 拍摄角度、光线、洗头间隔与产品 |
| 喜欢与不便 | 分别记录外观和维护 |
| 下次改变 | 只选一个优先项 |
| 结论范围 | 观察次数，哪些变化无法排除 |
