# 穿搭对比模板

[模板目录](../experiments/README.zh-CN.md) · [English index](../experiments/README.md)

复制到私人目录后填写。先用已有衣物比较，不需要为完成记录购买新单品。个人照片留在私人位置。

| 字段 | 填写内容 |
| --- | --- |
| 记录编号与日期 | 自定稳定编号 |
| 场合与天气 | 工作、通勤或其他实际场景 |
| 希望的效果 | 用自己的话描述 |
| A 组合 | 单品编号、尺码和穿法 |
| B 组合 | 仅改变的单品或穿法 |
| 一起变化的条件 | 无法保持相同的因素 |
| 拍摄条件 | 距离、光线、角度与姿势 |
| 站立效果 | 喜欢或不喜欢的具体部位 |
| 活动感受 | 坐下、走动、抬手 |
| 实穿后的感受 | 舒适、温度与整理次数 |
| 私人照片编号 | 不放公开地址 |
| 当前选择及理由 | 外观偏好与舒适度分开写 |
| 下次比较 | 一个优先问题 |
| 结论范围 | 本次场合、次数与限制 |
