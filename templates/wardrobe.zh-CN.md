# 衣橱记录模板

[模板目录](../experiments/README.zh-CN.md) · [English index](../experiments/README.md)

复制到私人目录后填写，一件衣服一条记录。这里不收集实际尺寸、购买凭据或个人库存。

| 字段 | 填写内容 |
| --- | --- |
| 单品编号 | 自定稳定编号 |
| 类别与用途 | 实际穿着场合 |
| 品牌型号与尺码 | 按标签记录 |
| 平铺测量 | 写清位置、单位和测量方法 |
| 成分及洗标 | 按标签记录，不凭触感猜成分 |
| 颜色与面料观感 | 具体观察 |
| 舒适与限制 | 坐下、抬手和走动的情况 |
| 已有搭配 | 关联私人穿搭记录编号 |
| 使用频率 | 明确观察起止日期 |
| 维护与修改 | 实际时间、费用和结果 |
| 待解决问题 | 修补、调整或继续观察 |
| 是否需要补充单品 | 先写现有衣物无法满足的具体需求 |
