# Practice templates

[English](README.md) · [简体中文](README.zh-CN.md)

Copy a template to your private project data directory before completing it. This public folder contains instructions only; there are no personal results.

| Template | Purpose |
| --- | --- |
| [Research note](../templates/research-note.zh-CN.md) | Track a question, a source, a claim and a possible counterexample |
| [Haircut](../templates/haircut.zh-CN.md) | Compare the salon result with your own routine and later growth |
| [Outfit](../templates/outfit.zh-CN.md) | Compare one change while recording comfort and context |
| [Wardrobe](../templates/wardrobe.zh-CN.md) | Record existing garments, fit and maintenance before buying |

The templates are currently in Chinese. They are proposed recording tools, not completed experiments. Record how many observations support a conclusion and which conditions changed. Do not generalize a personal preference to a whole population.

Read the [privacy boundary](../docs/privacy.md) before sharing any summary. Return to the [main index](../README.md) for topic notes and source records.
