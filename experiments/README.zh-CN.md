# 实践模板

[English](README.md) · [简体中文](README.zh-CN.md)

先把模板复制到私人项目数据目录，再填写。这个公开目录只提供说明，没有个人实践结果。

| 模板 | 用途 |
| --- | --- |
| [研究笔记](../templates/research-note.zh-CN.md) | 记录问题、来源、判断和可能的反例 |
| [剪发复盘](../templates/haircut.zh-CN.md) | 比较店内效果、自己打理和长长后的变化 |
| [穿搭对比](../templates/outfit.zh-CN.md) | 改变一个条件，记录舒适度与场合 |
| [衣橱记录](../templates/wardrobe.zh-CN.md) | 购买前先了解已有衣物的尺寸、搭配和维护 |

模板目前提供中文版本。它们是拟定的记录工具，尚无完成的试验。得出判断时写明观察了几次、哪些条件一起变化，不把个人偏好推广到整个人群。

分享总结前先看[隐私边界](../docs/privacy.zh-CN.md)。主题笔记和来源记录见[首页](../README.zh-CN.md)。
