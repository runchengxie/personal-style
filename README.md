# Personal Style

[English](README.md) · [简体中文](README.zh-CN.md)

A source-aware notebook for men's clothing and hairstyles. Learn how fit, hair structure and cultural references work, then test choices against your own preferences and daily routine.

The first edition contains Chinese topic notes, verified resource descriptions and blank practice templates. It does not contain completed book reviews or personal styling results. English translations of individual topic notes are not yet available.

## Start here

Read the [learning route](docs/start-here.zh-CN.md), choose one question, then use a [practice template](experiments/README.md). The [recording method](docs/method.zh-CN.md) explains evidence labels and source IDs.

| Area | Working conclusion | Evidence stage and scope | Main open question |
| --- | --- | --- | --- |
| [Hair](hair/fundamentals.zh-CN.md) | Describe length, volume, direction and texture before choosing a name | Design framework; professional curricula checked, no personal trials | Can the reference shape be maintained with the wearer's hair and routine? |
| [Fit](fashion/fit-and-proportions.zh-CN.md) | Compare garment measurements with a comfortable garment and movement | Proposed fitting protocol; no wear-test dataset | Which cut works in actual use? |
| [Colors and fabrics](fashion/colors-and-fabrics.zh-CN.md) | Compare materials and colors under consistent conditions | Practical checklist; no universal color diagnosis | What remains comfortable and appealing after wear and washing? |
| [Cultural styles](fashion/styles-and-culture.zh-CN.md) | Study design and context without making ancestry a dress rule | Publisher descriptions and a limited hair study; no comparative styling trial | Which elements matter to the intended look? |
| [References](references/books.zh-CN.md) | Match a source to the question it can answer | Catalog and selected abstract checks; books not read in full | Which chapters support a specific claim? |
