# 怎样开始研究自己的穿搭与发型

[返回中文首页](../README.zh-CN.md) · [English index](../README.md)

先选一个能在下一次理发或试穿时回答的问题。第一次不必把所有教材买齐，也不必一次改完整体形象。

## 下一次要理发

读[发型基础](../hair/fundamentals.zh-CN.md)，把喜欢的参考图拆成刘海、顶部和两侧几个部分。随后填写[理发沟通单](../hair/barber-brief.zh-CN.md)，带两三张不同角度的授权参考链接去沟通。

选资料时，可以先看 [B-003 Sassoon 男士教材](../references/books.zh-CN.md#b-003)和 [B-005 Pivot Point](../references/books.zh-CN.md#b-005)的介绍，确认它们讨论的问题是否符合需求。这里尚未完成教材阅读，不能提供已经核对正文的章节结论。

剪完当天和自己洗头后各记录一次。两次效果相差多少，比店里刚吹好的照片更能说明日常维护是否方便。记录留在私人目录，用[剪发模板](../templates/haircut.zh-CN.md)即可。

## 下一次要试衣服

从[合身与比例](../fashion/fit-and-proportions.zh-CN.md)开始。找一套穿着舒服的现有衣物作为比较对象，把坐下、抬手和走动的感受记下来，再判断要不要换版型。

研究经典男装可以从 [B-001《绅士》](../references/books.zh-CN.md#b-001)入手。对日本如何改造美式服装感兴趣，可以再查 [B-002 Ametora](../references/books.zh-CN.md#b-002)。前者是经典男装指南，后者讨论文化历史，二者回答的问题不同。

先用已有衣服搭两套，通过[穿搭模板](../templates/outfit.zh-CN.md)比较。确认缺少哪一件之后再考虑购买，避免把阅读清单变成购物清单。

## 怎样让笔记越用越有帮助

每篇只处理一个问题，写清来源支持到哪里。尝试结果可以推翻原来的猜想，也可以暂时没有结论。下次需要改变什么、哪些条件必须保持相近，写进记录就够了。

完整规则见[记录方法](method.zh-CN.md)，个人资料存放方式见[隐私说明](privacy.zh-CN.md)。
