# Personal Style design

Approved scope: a public `personal-style` GitHub repository for men's clothing and hairstyles, with an English README, Chinese entry point and initial Chinese notes. Personal records stay outside the public repository.

## Approaches

The founding discussion considered a public knowledge base with separate personal storage, a single private repository, and delegating the choice. The owner selected the public knowledge base with personal records elsewhere and approved the proposed content structure.

## Deliverable

Use plain Markdown for hair variables, barber communication, clothing fit, colors and fabrics, cultural styles, source records and blank practice templates. Keep source identities and reading depth explicit. Include Gentleman, Ametora and professional barber education where their official identity can be checked. Preserve unresolved conversational references as leads, not evidence.

No website, application, personal portrait analysis, private measurements, downloaded books or reference-image collection is included. Do not create a second private repository without a separate request. Original notes and source links are sufficient for this edition; no new licensing grant is selected.

## Verification and delivery

Check relative links, fragments, formatting, README parity, source scope and the staged public diff. Use a task worktree, a reviewed PR and the owner's standing integration authorization. Verify the current target before merge, preserve public noreply commit identity, then update the clean primary checkout and remove only the completed task branch and worktree. No deployment is required.
