# 公开笔记与私人记录

[English](privacy.md) · [简体中文](privacy.zh-CN.md)

这个仓库是公开的。这里保存原创、不能识别个人的知识笔记和空白模板。填写后的个人记录另放在 Git 工作目录之外的私人位置。

个人照片、身体与衣物尺寸、购物凭据、预约信息、位置细节和实际试验结果留在私人位置。原始材料、生成图片和报告也放在源码仓库之外。有配置好的项目数据目录时可以使用，但目录本身不会自动获得隐私保护、备份或加密。

忽略规则可以减少误加常见照片、PDF 和本地目录的机会。它不提供访问控制，已经被 Git 跟踪的文件仍会保留，强行添加或公开链接也可能泄露资料。每次推送前检查暂存差异和附件。之后删掉文件，历史提交里的内容仍然存在。

参考图片和授权书籍预览优先保留原链接。未经许可不上传扫描件、视频下载或第三方图片。确实要分享实践总结时，先去掉身份、私人路径和图片元数据。本库没有收录建库对话中的个人记录或原始人像。
