# 怎样记录来源与判断

[返回中文首页](../README.zh-CN.md) · [English index](../README.md)

一条笔记应当让后来的人看得出，哪些是来源原本的说法，哪些是整理者的解释，又有哪些需要自己试过才能回答。

## 两种状态分别记录

来源的阅读进度与一条判断的证据性质需要分开。出版社介绍已经查到，仍然不代表书中每一章都已核实。

| 来源进度 | 含义 |
| --- | --- |
| 待核实 | 尚未找到可确认的原始材料 |
| 介绍已核对 | 已查官方介绍、目录或正式书目，只确认身份和范围 |
| 摘要已读 | 已读论文摘要，正文方法和限制尚未完整核对 |
| 正文部分已读 | 明确列出阅读的章节或页码 |
| 正文已读 | 已读该版本全文，仍需区分原文与个人解释 |

| 判断类型 | 应当怎样写 |
| --- | --- |
| 研究发现 | 写清研究对象、方法、结果与限制，避免外推到未研究的问题 |
| 专业技术 | 给出教材版本和章节，说明适用的发质或操作条件 |
| 审美经验 | 标明作者偏好、文化场景与可能的例外 |
| 待试方案 | 用问题或假设表达，附上比较方法 |
| 个人观察 | 记录实际尝试次数和条件，只支持记录者的局部结论 |

首版主题中的试穿和造型检查表属于待试方案。它们没有经过本库的个人实践验证，不能标成研究结论或教材原文。

## 一条来源记录需要什么

资料编号以 `B-` 表示书籍、`C-` 表示课程、`R-` 表示研究、`P-` 表示待核实线索。编号建立后保持不变；修正链接时保留原编号和修正原因。

至少记录标题、作者或机构、稳定链接、访问日期、对应版本和阅读进度。引用书中具体结论时补上章节或页码；视频结论补作者、原链接和时间戳。网址可以更新，不能把原有证据记录一起删掉。

## 比较时控制什么

头发长度、刚洗头还是隔天、造型产品用量都会影响比较。衣服则需要记录具体尺码、穿着场合及活动感受。照片尽量保持距离、焦段、光线和姿势相近，并同时保留未筛选的观察。

一次只改变一个变量通常更容易解释结果；实际无法做到时，把一起变化的因素写出来。个人前后对比仍会受到主观偏好、期待和拍摄条件影响，不能据此声称某种设计对所有人都更好。

用[研究笔记模板](../templates/research-note.zh-CN.md)记录问题、反例和下一步。公开内容只保留去掉私人信息后的原创总结。
