# Public notes and private records

[English](privacy.md) · [简体中文](privacy.zh-CN.md)

This repository is public. Publish original, non-identifying notes and blank templates here. Keep completed personal records in a separate private location outside the Git checkout.

Personal photos, body and garment measurements, receipts, appointments, location details and private experiment results belong in that private location. Keep raw inputs and generated images or reports outside the source repository as well. Use the configured project data directory when available; it is not automatically private, backed up or encrypted.

The ignore file reduces accidental additions of common photos, PDFs and local folders. It is not an access control: Git still tracks previously committed files, and forced additions or links can disclose information. Review the staged diff and attachments before every public push. Deleting a file in a later commit does not remove its history.

Use source links for reference images and authorized book previews. Do not upload scans, video downloads or third-party images without permission. Remove identities, private paths and image metadata before deliberately sharing any practice summary. No personal record or original portrait from the founding conversation is included in this repository.
