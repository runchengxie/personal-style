# Contributing

[English](CONTRIBUTING.md) · [简体中文](CONTRIBUTING.zh-CN.md)

Open a focused pull request for a source correction, a new original note or an improvement to a blank template. Read the [recording method](docs/method.zh-CN.md) and [privacy boundary](docs/privacy.md) first.

Give new sources a stable ID and record the title, author or institution, URL, access date, edition and reading depth. A publisher description confirms a resource's identity and stated scope; it does not verify every claim in the book. Attribute aesthetic conventions and distinguish them from technical evidence and personal observations. Do not claim firsthand experience that was not supplied.

Write English in reader-facing files without a locale suffix and Chinese in `.zh-CN.md` files. If translating an existing document, link both versions near the top and keep their instructions and limitations aligned. Topic notes may start in Chinese only, as the root README explains.

Before submitting, run `git diff --check`, open every changed relative link including fragment targets, and review the staged diff for private records and unsupported claims. Keep summaries original and link authorized sources. Do not submit scans, downloaded videos or images without permission. There is no application build or deployment to run.
