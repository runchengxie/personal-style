# 带去理发店的沟通单

[返回中文首页](../README.zh-CN.md) · [English index](../README.md)

先让理发师理解希望保留的轮廓和每天愿意花的时间，再讨论具体长度。下面是空白沟通模板，填写后的个人资料留在私人目录。

| 项目 | 去理发前填写 |
| --- | --- |
| 希望呈现的感觉 | 自己用词描述 |
| 喜欢的参考 | 两三条授权图片或视频链接，注明喜欢哪部分 |
| 日常打理时间 | 平时真正愿意花的时间 |
| 自然状态 | 洗后、吹干后、隔天分别有什么变化 |
| 希望保留的部分 | 例如刘海长度或后部轮廓 |
| 最担心的情况 | 例如两侧外翘、厚重、需要频繁回剪 |
| 本次先试什么 | 一个主要改变 |

## 当面确认

请理发师看发旋、发际线和侧面头型，解释参考图中哪些部分需要调整。顶部和刘海的长度由现场判断，不把网上给出的厘米数直接当作要求。

问清耳周和后部的过渡高度，也看看自然状态下的轮廓。如果建议烫发，先了解不烫时能做到什么程度、后续怎样维持，再决定是否采用。

结束前请理发师演示一次自己能完成的吹风和产品用法，记下顺序、用量及大致回剪安排。自己洗头后再比较一次，结果记在[剪发模板](../templates/haircut.zh-CN.md)。
