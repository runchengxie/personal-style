# 颜色与面料的比较方法

[返回中文首页](../README.zh-CN.md) · [English index](../README.md)

颜色先看自己是否喜欢、整套是否协调，面料先看穿着和维护是否方便。下面是个人比较的待试方案，没有经过本库穿着试验，也不提供基于肤色的固定配色诊断。

## 比较颜色

先保留相同的裤子和鞋子，只换上衣，看看明暗、饱和程度和上下对比怎样改变观感。记录自己喜欢的效果，再在常去的场合观察一次。

拍照尽量使用相同光线和相机设置。自动白平衡、曝光和屏幕会影响颜色，一张照片不足以断言某人只能穿冷色或暖色。

颜色名称也可能很粗。同样叫白色，偏黄、偏灰和亮度不同，上身感觉会有差异。需要比较时记录具体单品和自己的观察，不只写颜色标签。

## 比较面料

| 观察内容 | 怎样记录 |
| --- | --- |
| 成分与结构 | 抄下标签，分别记录成分、织法和厚薄感 |
| 穿着感受 | 写明温度、活动强度，以及贴肤或闷热的感受 |
| 轮廓 | 观察垂坠、挺度与活动后的变化 |
| 维护 | 保留洗标，按标示清洗后记录缩水、起皱或变形 |
| 使用成本 | 记录实际清洗、熨烫和修补的时间与费用 |

同一种纤维可以制成不同厚度和结构的布料。仅凭“纯棉”“羊毛”等成分名称，无法完成对具体衣服的评价。没有穿洗过时，记录停留在标签与试穿观察，不写成长期使用结论。
